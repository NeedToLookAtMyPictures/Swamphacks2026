There are 3 tables

Locales:  {time_created: double, time_recieved: double, location: str, name: str, sender: str, comment: str}
Geolocations: {time_created: double, time_recieved: double, user: str, latitude: double, longitude: double }
Messages: {time_created: double, time_recieved: double, sender: str, reciever: str, content: str, is_dead: bool}

if message_age > 31 days, is_dead = True
if message reaches intended user, is_dead = True

When sever sees messages, if is_dead is true, it tells anyone that hooks up message is dead. If message is dead, and two people have message
then if one is dead both is dead. If the other person doesnt have dead message, they dont save it.
